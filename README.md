---

## 📖 Sobre o Projeto

Este repositório contém o código-fonte da aplicação voltada ao **Incentivo à Leitura**. O projeto busca oferecer uma plataforma amigável e acessível para engajar leitores, combinando boas práticas de UX/UI com uma arquitetura de código limpa, responsiva e performática.

---

## ✨ Funcionalidades

- 📱 **Interface Responsiva:** Navegação otimizada para desktops, tablets e dispositivos móveis.
- 🎨 **Design Focado no Usuário:** Layout intuitivo que facilita a acessibilidade e a navegação.
- ⚡ **Interatividade com JavaScript:** Elementos dinâmicos para enriquecer a experiência do leitor.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização, componentes visuais e layouts flexíveis.
- **JavaScript (ES6+):** Lógica do sistema, manipulação do DOM e interatividade.

---

Em conformidade com as diretrizes acadêmicas e profissionais, declara-se que ferramentas de **Inteligência Artificial** foram utilizadas como suporte técnico durante o desenvolvimento deste projeto nas seguintes etapas:
